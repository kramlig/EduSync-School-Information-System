## 🔄 Document Lifecycle

1. **Planning** → Documents start in `/plans/`
2. **Implementation** → Move to `/implementation/` when work begins
3. **Testing** → Test results go to `/testing/`
4. **Completion** → Summaries added to `/summaries/`
5. **Deployment** → Deployment docs in `/deployment/`
6. **Archival** → Old/deprecated docs move to `/archived/`

## 📝 Documentation Standards

- Use clear, descriptive filenames with UPPERCASE and underscores
- Include dates in time-sensitive documents (e.g., `*_NOV_6_2025.md`)
- Add status prefixes where helpful (e.g., `COMPLETE_*`, `PHASE1_*`)
- Keep README files in relevant subdirectories
- Update this index when adding new document categories

## 🆘 Need Help?

- **Can't find a document?** Use VS Code's search (Ctrl+Shift+F) to search all docs
- **Not sure which category?** Check multiple related folders
- **Document seems outdated?** Check `/summaries/` for more recent status
- **Need quick answers?** Start with `/quick-reference/`
