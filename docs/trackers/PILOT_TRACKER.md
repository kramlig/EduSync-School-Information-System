## 💬 **Feedback Collection**

### **Structured Questions for Week 1 Review:**

#### Usability
1. Was login/navigation intuitive? (1-5 scale)
2. What was confusing or frustrating?
3. What took longer than expected?
4. Did you need help? For what?

#### Features
5. Which feature did you use MOST?
6. Which feature would you use EVERY day?
7. What's missing that you expected to find?
8. What feature would you remove/simplify?

#### Value
9. Does this save you time vs current method? (Yes/No/Not sure)
10. Would you recommend this to colleagues? (Yes/No/Maybe)
11. What ONE thing would make you recommend it?
12. What's the biggest blocker to daily use?

#### Next Steps
13. Can we expand to 2-3 colleagues next week?
14. What should we fix FIRST before expanding?
15. Any DepEd compliance concerns?

## 🎯 **Decision Points**

### **End of Week 1:**
**IF**: Teacher uses it 3+ times AND finds it valuable  
**THEN**: Expand to 2-3 colleagues

**IF**: Teacher struggles or doesn't use it  
**THEN**: Deep dive interview → Fix issues → Re-test

**IF**: Teacher uses only 1-2 features  
**THEN**: Focus development on those features first

### **End of Week 3:**
**IF**: 3+ teachers actively using  
**THEN**: Prepare school admin presentation

**IF**: Mixed feedback  
**THEN**: Iterate another 2 weeks

**IF**: Low adoption  
**THEN**: Reassess product-market fit
