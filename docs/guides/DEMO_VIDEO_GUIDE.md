## 🛠️ Recording Tools (Free Options)

### **Option 1: OBS Studio (Recommended - Free & Professional)**

**Download:** https://obsproject.com/

**Setup:**
1. Install OBS Studio
2. Create a new scene: "Browser"
3. Add source: "Window Capture"
4. Select your browser window
5. Add audio: "Audio Input Capture" (your microphone)
6. Settings:
   - Output: 1920x1080, 30fps
   - Encoder: x264
   - Bitrate: 2500 Kbps

**Recording Workflow:**
1. Open browser in full-screen mode (F11)
2. Start OBS recording
3. Follow script shot-by-shot
4. Stop recording
5. Edit in DaVinci Resolve (free) or Shotcut

---

### **Option 2: Loom (Easy & Fast)**

**Website:** https://loom.com (Free tier: 5 min limit per video)

**Pros:**
- Super easy to use
- Webcam + screen recording
- Instant share links
- Auto-transcription

**Cons:**
- 5-minute limit (free)
- Less control over editing

**Workflow:**
1. Install Loom Chrome extension
2. Click Loom icon → "Record Screen"
3. Follow script
4. Auto-uploads to cloud
5. Get shareable link

---

### **Option 3: Windows Game Bar (Built-in)**

**Shortcut:** `Windows + G`

**Pros:**
- Already installed
- Quick and simple

**Cons:**
- Limited features
- No advanced editing

## 🎤 Voiceover Tips

### **Equipment:**
- **Ideal:** USB microphone ($30-50)
- **Budget:** Smartphone earbuds with mic
- **Free:** Built-in laptop mic (quiet room)

### **Recording Environment:**
- Close windows (reduce noise)
- Turn off fans/AC
- Use a closet with clothes (dampens echo)
- Record at night (less ambient noise)

### **Voice Tips:**
- Speak clearly and enthusiastically
- Smile while talking (it shows in your voice!)
- Pause between sentences (easier to edit)
- Record in short segments (not all at once)

### **Alternative: Text-to-Speech**
If you're not comfortable recording voiceover:
- **ElevenLabs** (realistic AI voices): https://elevenlabs.io
- **Natural Reader** (free): https://naturalreader.com
- **Google Text-to-Speech**: Built into Chrome

### **Recording Environment**
- [ ] Quiet room
- [ ] Good lighting (if showing face)
- [ ] Clean desktop background
- [ ] Microphone tested
- [ ] Do a 10-second test recording

## 🎬 Recording Day Workflow

### **Morning of Recording:**
1. ☕ Coffee/tea (relax your voice)
2. 🧘 Practice script 2-3 times
3. 🎤 Test microphone levels
4. 🖥️ Set up demo data
5. 🔇 Silence notifications

### **During Recording:**
1. **Take 1:** Record full walkthrough (don't worry about mistakes)
2. **Review:** Watch and note sections to re-record
3. **Take 2:** Re-record problem sections only
4. **Break:** 5-minute rest
5. **Final Check:** Watch full video

### **Common Mistakes to Avoid:**
- ❌ Rushing through features
- ❌ Mouse moving too fast
- ❌ Clicking before voiceover finishes
- ❌ Background noise (dogs, cars, phones)
- ❌ Forgetting to record audio

## 📤 Publishing

### **YouTube Upload:**
1. Create unlisted or public video
2. **Title:** "EduSync Demo - School Information System for Philippines"
3. **Description:** Include website link and features
4. **Tags:** school management, DepEd, Philippines, SIS
5. **Thumbnail:** Create custom thumbnail (1280x720)

### **Embedding on Landing Page:**
1. Get YouTube video ID from URL
2. Update `landingPageConfig.ts`:
```typescript
export const DEMO_VIDEO = {
  youtubeId: 'YOUR_VIDEO_ID_HERE',
  title: 'EduSync System Walkthrough',
  duration: '2:30'
};

export const LANDING_PAGE_FEATURES = {
  showDemoVideo: true,  // ← Enable video
};
```
