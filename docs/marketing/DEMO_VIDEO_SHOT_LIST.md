## �📋 Pre-Recording Setup Checklist

### **Browser Setup:**
- [ ] Use **Chrome** in **Incognito Mode** (`Ctrl + Shift + N`)
- [ ] Set browser zoom to **100%** (`Ctrl + 0`)
- [ ] Hide bookmarks bar (`Ctrl + Shift + B`)
- [ ] Close all other tabs
- [ ] Clear any notifications
- [ ] **Full screen mode OFF** (show browser UI for realism)

### **Demo Account Setup:**
- [ ] Sign in to: `admin@edusync.local` / `admin123`
- [ ] Or use production demo account
- [ ] Verify data is seeded with realistic Filipino names
- [ ] Pre-generate at least 1 Form 138 (so generation is instant)

### **System Cleanup:**
- [ ] Close Slack, Teams, email notifications
- [ ] Set Windows to "Do Not Disturb"
- [ ] Close desktop icons (right-click desktop → View → Show desktop icons: OFF)
- [ ] Use clean desktop wallpaper (solid color or minimal)

### **Recording Tool:**
- [ ] **Option A:** OBS Studio (free, professional)
- [ ] **Option B:** Windows Game Bar (`Windows + G`)
- [ ] **Option C:** Loom (easiest)
- [ ] Test recording (5 seconds) to verify audio/video quality

## 💡 Pro Tips

### **Mouse Movement:**
- Move slowly and intentionally
- Pause briefly before clicking
- Highlight hover effects (cards lighting up)

### **Timing:**
- Stay still for 2 seconds at the start of each shot
- Stay still for 2 seconds at the end of each shot
- This gives the editor "breathing room" to cut

### **Retakes:**
- If you mess up, just start that shot over
- Don't try to edit while recording
- Better to have 3 good takes than 1 perfect marathon

### **Speed:**
- Some actions (typing, form filling) will be sped up 2-3x in editing
- So type naturally, don't rush
- Navigation should be normal speed
