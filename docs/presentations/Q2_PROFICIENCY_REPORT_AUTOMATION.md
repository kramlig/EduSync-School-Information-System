6. ✅ **Export matches exact DepEd Excel format**

```
┌────────────────────────────────────────────────────────────────────────────────┐
```

```
│ MOTHER TONGUE - GRADE 3 (Columns J-K)                                           │
│ J: % of Learners with 75% MPS and above                                         │
│ K: Mean Percentage Score (MPS)                                                  │
│                                                                                 │
│ READING & LITERACY - GRADES 1-3 (Columns L-S)                                   │
│ L-M: Grade 1 (% ≥75%, MPS)                                                      │

│ P-Q: Grade 3 (% ≥75%, MPS)                                                      │
│                                                                                 │
│ ENGLISH - GRADES 4-6 (Columns R-W)                                              │
│ R-S: Grade 4 (% ≥75%, MPS)                                                      │
│ T-U: Grade 5 (% ≥75%, MPS)                                                      │
│ V-W: Grade 6 (% ≥75%, MPS)                                                      │
│                                                                                 │
└────────────────────────────────────────────────────────────────────────────────┘
```

### Calculation Formulas

| Metric | Formula |
|--------|---------|
| **MPS (Mean Percentage Score)** | `SUM(all student Q2 grades) / COUNT(students) × 100` |
| **% with 75%+ MPS** | `COUNT(students with Q2 ≥ 75) / COUNT(total students) × 100` |
| **Kindergarten Levels** | Count of students at each proficiency level |
