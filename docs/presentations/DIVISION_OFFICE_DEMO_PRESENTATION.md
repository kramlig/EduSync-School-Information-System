# 🏫 What is EduSync?

## A Complete School Management Ecosystem

**EduSync** is a **cloud-based, DepEd-compliant School Information System** designed specifically for Philippine schools.

### Key Highlights:
- ✅ **100% DepEd-Compliant** - All forms, calculations, and reports follow official guidelines
- ✅ **Cloud-Based** - Accessible anywhere, anytime, on any device
- ✅ **Offline-Ready** - Works without internet, syncs when connected
- ✅ **Modern & User-Friendly** - Intuitive interface requiring minimal training

## Complete Gradebook System

### Features:
- **Quarterly Grading** - Q1, Q2, Q3, Q4 with automatic final grade calculation
- **DepEd Components** - Written Works, Performance Tasks, Quarterly Assessments

- **Core Values Assessment** - Maka-Diyos, Maka-tao, Makakalikasan, Makabansa

- 📊 **Instant reports** - No more manual compilation

# ❓ Frequently Asked Questions

**Q: Is the data secure?**
> Yes, we use enterprise-grade encryption and Firebase's security infrastructure. All data is stored in certified data centers.

**Q: Can we use it offline?**
> Yes! EduSync is a Progressive Web App (PWA). You can continue working offline, and changes sync automatically when connected.

**Q: How long does training take?**
> Most users are productive within 2-4 hours. The interface is designed to be intuitive and user-friendly.

**Q: Can we import existing data?**
> Yes, we support Excel/CSV imports and offer free migration assistance for pilot schools.

**Q: Is it mobile-friendly?**
> Absolutely! Works on phones, tablets, and desktops. Same experience across all devices.
