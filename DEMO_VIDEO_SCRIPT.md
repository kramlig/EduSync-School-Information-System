## 📋 Pre-Recording Checklist

- [ ] Clear browser cache (Ctrl+Shift+Delete)
- [ ] Close unnecessary browser tabs
- [ ] Disable browser extensions that might interfere
- [ ] Check audio/microphone levels
- [ ] Test screen recording software
- [ ] Prepare a clean browser window
- [ ] Have credentials ready on notepad
- [ ] Set browser zoom to 100%
- [ ] Turn off notifications (Focus mode on Windows)

---

## 🎥 Recording Tips

1. **Pace:** Speak slowly and clearly. Pause between sections.
2. **Mouse Movement:** Move cursor smoothly, avoid quick jerks
3. **Highlights:** Briefly hover over important elements as you mention them
4. **Transitions:** Give 1-2 seconds between clicking and speaking
5. **If You Make a Mistake:** Just pause, count to 3, and restart that sentence. You can edit later.
